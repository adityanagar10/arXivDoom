# Android app (planned)

Not started yet. When work begins, this directory will hold a standalone
Android Studio project (Kotlin, Jetpack Compose recommended to mirror the
iOS app's SwiftUI structure) implementing the same core features as the
iOS app in `../ios/`:

- Follow arXiv categories, doomscroll new papers by title/abstract
- In-app PDF reading
- Local offline library of saved papers

See `../docs/superpowers/specs/` for the product specs that apply to both
platforms, and `../README.md` for the overall project structure.
